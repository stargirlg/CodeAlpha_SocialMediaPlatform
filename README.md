# CodeAlpha - Social Media Platform

A mini social media web application built as part of the **CodeAlpha Full Stack Development Internship**. Users can create profiles, publish post updates, reply with comments, and like community posts[cite: 2].

---

## Features

- **User Accounts**: Registration and login system backed by persistent user records[cite: 2].
- **Community Feed**: Dynamic feed rendering posts in reverse chronological order[cite: 2].
- **Interactive Engagement**: Like counters and comment threads for each post[cite: 2].

---

##  Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (DOM Manipulation, Async Fetch API)[cite: 2]
- **Backend**: Node.js, Express.js (RESTful APIs)[cite: 2]
- **Database**: SQLite3 (Users, Posts, Comments schemas)[cite: 2]
- **Development Environment**: GitHub Codespaces, Git
